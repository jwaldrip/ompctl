Get started

Four commands and a code.

Run these on the machine that runs OMP. Keep the machine awake and the daemon running while you're away.

  1. Install the daemon

    ompd self-install

  2. Start it

    ompd start

  3. Invite your device

    ompd invite "my phone" --scopes read,prompt

    Scan the QR code or paste the token into the app. This invite grants reading and prompting; add approve to answer approvals.

  4. Check the connection

    ompd doctor

Pair once, then open your sessions

The app opens the sessions the daemon already holds. Open the web app or get the native app source.

Granted per device

A device gets exactly what you gave it.

Pairing grants a scoped token. A phone paired for reading and prompting cannot answer approvals or manage your agents.

Four scopes, chosen when you pair.
ScopeWhat it permits
readSee sessions, transcripts, agents and cost.
promptSend messages into a session.
approveAnswer approvals and plan reviews.
manageProvision hosts, change settings and create agents.

ompd devices lists pairings. ompd revoke ends one. ompd rotate re-mints it. ompd audit shows what devices did.
